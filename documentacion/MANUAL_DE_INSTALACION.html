1. Introducción y Arquitectura del Sistema

El presente manual proporciona instrucciones detalladas para la instalación, configuración y puesta en marcha del Sistema de Monitoreo y Dosificación Automática de Químicos para Piscinas. El software ha sido construido bajo una Arquitectura Cliente-Servidor desacoplada:

  • Servidor (Backend & IA): Desarrollado en Python con FastAPI, implementa una red neuronal recurrente bidireccional BiLSTM (PyTorch) para predicción a 24/48 horas de pH, turbidez y temperatura, con modelos complementarios en XGBoost y servicios de telemetría IoT.
  • Cliente (Frontend SPA): Single Page Application construida con React 19, Vite y TailwindCSS, con visualización de telemetría en tiempo real y gráficos dinámicos interactivos.
  • Base de Datos Cloud: Alojada en PostgreSQL en Supabase Cloud bajo el esquema relacional piscina_lstm3.
  • Módulo de Hardware IoT: Integración de microcontroladores ESP32, sensores sumergibles, actuadores peristálticos y simulador de laboratorio.

3. Procedimiento de Instalación

3.1 Despliegue Rápido con Docker (Recomendado Multiplataforma)

Con Docker Desktop activo en Windows o Linux, sitúese en la raíz del proyecto y ejecute:

cd sistema-piscina
docker compose up -d --build

Esto compila y levanta automáticamente los servicios:

  • Frontend (React + Nginx): http://localhost:3000
  • Backend (FastAPI + PyTorch): http://localhost:8000/docs
  • Acceso desde otros dispositivos: http://<IP-DEL-SERVIDOR>:3000

3.2 Instalación Nativa en Windows (Paso a Paso)

Paso 1: Backend (FastAPI + IA):

cd sistema-piscina\backend
python -m venv venv
.\venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cd ..
python -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload

Paso 2: Frontend (React + Vite) en una segunda consola:

cd sistema-piscina\frontend
npm install
npm run dev -- --host 0.0.0.0

3.3 Instalación en Linux (Ubuntu / Debian)

# 1. Dependencias del sistema
sudo apt update && sudo apt install -y python3 python3-pip python3-venv git curl nodejs npm

# 2. Servidor Backend
cd sistema-piscina/backend
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cd .. && python3 -m uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 &

# 3. Cliente Frontend
cd sistema-piscina/frontend
npm install && npm run build
npm run preview -- --host 0.0.0.0 --port 3000

3.4 Acceso y Operación en Dispositivos Móviles (Android / iOS)

El frontend está diseñado bajo estándares PWA y Responsive Design. Los operadores pueden usar el sistema desde cualquier teléfono móvil conectado a la red Wi-Fi:

  1. Conecte el móvil a la misma red Wi-Fi de la computadora servidora.
  2. Obtenga la dirección IP local de la PC con ipconfig (ejemplo: 192.168.1.50).
  3. Abra Google Chrome (Android) o Safari (iOS) e ingrese a: http://192.168.1.50:3000
  4. Seleccione "Agregar a la pantalla principal" para instalarlo en modo aplicación nativa sin barra de direcciones.

5. Solución de Problemas Comunes

Problema Causa Solución
Fallo de conexión a Supabase Puerto 5432 bloqueado por el firewall. Cambiar en .env a SUPABASE_DB_PORT=6543 (Session Pooler) y reiniciar el backend.
Puerto 8000 o 3000 ocupado Servicio anterior quedó en segundo plano. En Windows ejecutar taskkill /F /IM python.exe /IM node.exe.
Error CORS en navegador Petición desde IP no permitida. Verificar que CORS_ORIGINS=* esté configurado en .env.
Bloqueo por intentos fallidos Más de 3 contraseñas erróneas. Mecanismo de seguridad antibruerza. Espere 5 minutos para el desbloqueo automático.
